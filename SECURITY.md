# Security Policy

## Supported Versions

Currently, only the latest major release of the **Prismo Constructions Backend** API is supported with security updates. We encourage all users to run the latest version to ensure they have the most recent security patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a priority for the Prismo Constructions project. Since this backend handles sensitive data such as authentication, project management, and client approvals, we take all vulnerabilities seriously.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them by emailing us directly at:
**dulanjanrmd@gmail.com**

### What to include in your report:
* A description of the vulnerability and its potential impact.
* Detailed steps to reproduce the vulnerability.
* Any relevant logs, screenshots, or code snippets.
* Your contact information.

### What to expect:
* We will acknowledge receipt of your vulnerability report within 48 hours.
* We will send you regular updates on our progress as we investigate and develop a fix.
* Once the issue has been resolved, we will publish a security advisory and notify you.

Thank you for helping keep Prismo Constructions secure!
